Implementation & Academic Highlights

1

Center-of-Mass Preprocessing

Replicates Yann LeCun's MNIST methodology in JavaScript: extracts the digit's bounding box, rescales into a 20×20 matrix, and shifts the center of mass to coordinates (14, 14).

2

Dual-Block Deep CNN

Built with 32 & 64 3×3 convolution filters, Batch Normalization, Max Pooling, and Dropout (0.25 & 0.40) achieving an outstanding 99.46% test accuracy on 10,000 unseen test samples.

3

100% In-Browser Execution

Weights are compiled to pure binary format (1.79 MB) and executed directly in the user's browser using TensorFlow.js WebGL/WebAssembly acceleration, requiring zero server roundtrips.
